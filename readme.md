# 一、快速使用手冊（給長者／測試者）

**巴士到站 App（BusScheduleETA）**

## 打開 App 之後
首頁有最多 9 個彩色大按鈕，每個是你常用的「路線 + 方向 + 上車站」。

## 查幾多分鐘有車
1. 用手指**按一下**那個常用按鈕。
2. 大字會顯示「還有幾分鐘」或「即將到站」。
3. 下面還有第 2、第 3 班。畫面約每 30 秒自動更新。
4. 左上角箭咀返回。

## 第一次：加入常用巴士
1. 按右下角 **＋**。
2. 輸入路線號碼（例如 `72`）。想只要剛好 `72`，在後面多打一個**空格**。
3. 選「往邊度」。
4. 選你平時上車站。
5. 完成後會回到首頁，多了一個按鈕。

## 刪除常用
**長按**那個按鈕 → 按「刪除」。

## 小提示
- 資料只存在你這部手機。
- 右上角扳手暫時顯示「功能建設中」。
- 城巴第一次載入車站可能要等十幾秒，請稍等。

有問題請聯絡 Chan Cimiy，最好連截圖一齊畀。

# 二、App 功能說明書

**專案名稱：** BusScheduleETA  
**套件名稱：** `org.cimiy.busscheduleeta`  
**對象：** 視力或操作較吃力的長者，常用固定幾條巴士線。

## 設計原則
- 少步驟：日常只需「一按」就看到到站時間。
- 大字、高對比；首頁用不同底色方便分辨。
- 到站以「分鐘」為主，鐘點為輔；少於 1 分鐘顯示「即將到站」（同一行大字）。

## 功能一覽

| 功能 | 說明 |
|------|------|
| 常用行程首頁 | 最多 9 個（3×9 格），顯示公司、路線、終點、上車站 |
| 一按查 ETA | 顯示下一班超大分鐘數，以及第 2、第 3 班；約 30 秒刷新 |
| 新增常用 | ＋ → 搜尋路線 → 選方向 → 選車站 → 存入手機 |
| 路線搜尋 | 預設「開頭相符」；輸入後加空格＝只顯示完全相同號碼 |
| 長按刪除 | 確認後刪除；少於 9 個時「＋」會再出現 |
| 公司資料 | 支援九巴（KMB）、城巴（CTB） |
| 異常提示 | 無班次／斷網用清楚中文；重要提示帶圖示（成功／警告／施工中） |
| 設定 | 右上角扳手暫為「功能建設中」 |

## 使用流程（詳細）
1. **日常：** 首頁 → 按常用 → 看分鐘 → 返回。
2. **新增：** ＋ → 等路線下載 → 搜尋 → 選方向（載入中會禁用按鈕）→ 等車站列表 → 選站。
3. **刪除：** 長按 → 確認。

## 已知限制
- 未有地圖、未有定位自動找站。
- 未有雲端同步；換機或刪 App 會失去常用清單。
- 城巴站名首次要逐個查詢，較慢，並受 API 頻率限制。
- 聯營線暫未自動合併成同一按鈕。
- 設定頁功能尚未實作。

## 建議之後可加
字體大小設定、常用行程排序、離線快取更多站名、聯營線合併。
